# 💻 Carine Lima | Developer Portfolio

Meu portfólio pessoal como **desenvolvedora de software**, criado para reunir meus principais projetos, tecnologias, experiências e um pouco da minha trajetória no desenvolvimento.

Mais do que uma vitrine de projetos, este portfólio representa minha evolução na programação e a construção contínua da minha carreira em tecnologia. 🚀

---

## ✨ Sobre o projeto

O portfólio foi desenvolvido com foco em uma experiência moderna, responsiva e intuitiva, permitindo conhecer de forma rápida:

* 👩‍💻 Quem sou
* 🛠️ Minhas principais tecnologias
* 🚀 Projetos desenvolvidos
* 📚 Minha trajetória e estudos
* 💼 Experiências e serviços
* 📩 Formas de contato

O objetivo foi construir uma interface que transmitisse minha identidade como desenvolvedora, mantendo um visual profissional, moderno e organizado.

## 🚀 Projetos em destaque

O portfólio reúne projetos desenvolvidos durante minha evolução como desenvolvedora, incluindo aplicações web, sistemas e projetos autorais.

### 💰 Sistema Financeiro

Aplicação web para gerenciamento de receitas e despesas, com autenticação, filtros, gráficos, recorrências e exportação de dados.

**Tecnologias:** Python, Flask, SQLite, HTML, CSS e JavaScript.

### ☕ SaaS para Cafeteria

Sistema completo para gerenciamento de cafeteria, com dashboard, produtos, pedidos, relatórios, configurações e cardápio digital.

**Tecnologias:** Python, Flask, HTML, CSS, JavaScript e banco de dados.

### 📅 Sistema de Agendamento

Aplicação voltada para gerenciamento de serviços e horários, criando uma experiência simplificada tanto para clientes quanto para administradores.

### 🌐 Landing Pages

Desenvolvimento de páginas comerciais responsivas e personalizadas, com foco em apresentação profissional, experiência do usuário e conversão.

### 🎲 Projeto Loteria

Aplicação interativa desenvolvida para trabalhar lógica de programação, geração de números e manipulação dinâmica da interface.

### 💜 BTS Magic Universe

Projeto autoral e interativo inspirado em um universo dividido em sete mundos, desenvolvido com HTML, CSS e JavaScript.
